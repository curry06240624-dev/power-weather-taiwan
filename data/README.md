# Data

`raw/` holds a copy of every file the notebook downloads, exactly as downloaded on 14 November 2026, so the results can
be repeated even if a source later changes (Taipower's "last three years" file rolls forward every January).

| File | Source | Licence |
|---|---|---|
| `taipower_reserve_2023_2025.csv` | Taipower, daily peak reserve and reserve rate, 2023–2025 | Open Government Data License, Taiwan v1.0 |
| `taipower_reserve_2026.csv` | Taipower, daily peak reserve and reserve rate, this year (data.gov.tw 25850) | same |
| `taipower_daily_2025_2026.csv` | Taipower, full daily supply table (data.gov.tw 19995) | same |
| `calendar_2023.csv` to `calendar_2026.csv` | DGPA government office calendar (data.gov.tw 14718) | same |
| `weather_observed.json` | Open-Meteo archive API, seven cities, daily | CC BY 4.0 (weather data by Open-Meteo.com) |
| `weather_dayahead_forecast.json` | Open-Meteo previous-runs API, the forecast made one day earlier, hourly | CC BY 4.0 (weather data by Open-Meteo.com) |
